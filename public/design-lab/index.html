שני כיוונים חדשים — לפני יישום מלא

עצירת ליטושי PR #1075. כאן מוצגים שני כיווני עיצוב שונים באמת ל־Hero + מקטע WhatsApp, בלי תלות בפריסת עמוד הבית הישנה. אחרי בחירה — ניישם את אותה שפה בכל העמוד.

  • mondayHero כהה ממורכז, בחירה/אינטראקציה, ומסכי מוצר לבנים שפולשים מלמטה כשכבות.
  • Linearטיפוגרפיה מדויקת, עומק כהה, UI כאלמנט מרכזי — לא כרטיסיות שיווקיות.
  • StripeHero אסימטרי, רקע עשיר, המחשת מוצר אחת ממוקדת במקום דשבורד ענק.
  • HubSpotגוף בהיר, חיבור ויזואלי בין מוצרים, UI snippets במקום צילום מסך שלם.
  • Salesforceהוכחה עסקית ו־CTA ברור; פחות רלוונטי ל־Hero שלנו אך מחזק מקטעי אמון בהמשך.

כיוון A · Deep Stage

monday + Linear. Hero סגול עמוק ממורכז. מוצר עולה מלמטה כשלוש שכבות ממוקדות. WhatsApp על רקע בהיר עם טלפון + תיבה + CRM.

  • קומפוזיציה אנכית דרמטית
  • מסכי מוצר כ־peek layers
  • מובייל: שכבות פשוטות יותר, בלי דשבורד רחב

כיוון B · Precision Ribbon

Stripe + HubSpot. Hero אסימטרי עם במה מוצר אחת מתחלפת. WhatsApp כרצועת תהליך אופקית: שיחה → תיבה → כרטיס.

  • שליטה מדויקת על מוקד אחד
  • מעבר שכבות CRM/WA/משימה
  • מובייל: הרצועה נערמת אנכית בלי חיתוך דסקטופ

מערכת עיצוב מוצעת (משותפת לשני הכיוונים)

צבעים: סגול מותג `#5b21b6`, כחול `#1d4ed8`, indigo עמוק, lavender/לבן לגוף העמוד. Hero כהה → רוב העמוד בהיר.

טיפוגרפיה: Assistant 800 לכותרות גדולות, 550–600 לגוף. כותרות קצרות, 2–3 שורות.

כפתורים: מלבניים (`border-radius: 0.2rem`) בלבד. Primary לבן על Hero / סגול על בהיר.

המחשות: crops ממוקדים מתוך מסכי דמו אמיתיים + סרטונים קצרים. אסור דשבורד מלא בלתי קריא.

אנימציה: כניסת שכבות, החלפת מוקד, מעברי תהליך. ללא typing / loaders. כיבוד `prefers-reduced-motion`.
